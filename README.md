

# KeyGuard - Gerenciador Simples de Senhas

Site: https://bresodev.github.io/KeyGuard/

Este é um sistema básico para armazenar, visualizar e gerenciar suas senhas localmente no navegador. Ele funciona diretamente na página, usando o armazenamento local (localStorage), sem necessidade de servidor.

## O que faz?

- Permite salvar combinações de site, email e senha de forma rápida.
- Exibe suas senhas salvas organizadas para fácil visualização.
- Permite apagar senhas específicas.
- Oferece uma forma simples de exportar e importar suas senhas via código.
- Utiliza uma criptografia simples (ROT13) para "esconder" as informações na visualização e no armazenamento.

## Como funciona?

1. Você insere o site, email e senha nos campos e clica em "Salvar".
2. Os dados são armazenados no navegador de forma local e exibidos em uma lista.
3. Pode clicar no cadeado no topo para exportar suas senhas em formato de código, que pode ser salvo e reutilizado depois para importar.
4. Também há uma proteção inicial via senha, que impede o acesso sem autenticação.

## Por que usar?

- Para quem quer um gerenciador de senhas simples, direto e sem depender de internet.
- Ideal para guardar senhas rápidas e organizá-las sem complicação.
- Total controle das suas senhas, pois ficam salvas apenas no seu navegador.

## Atenção

- Este projeto não é recomendado para senhas muito sensíveis, pois usa uma criptografia básica e o armazenamento é local.
- Mantenha seu navegador seguro para evitar acesso não autorizado.

## Como usar

1. Abra a página e faça login com a senha configurada.
2. Adicione seus dados nos campos e salve.
3. Use o cadeado para exportar ou importar suas senhas.
4. Apague senhas clicando no botão "Apagar" de cada entrada.
